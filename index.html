FAQ

Perguntas frequentes

Preciso usar Firebase?

Não. Este site não utiliza Firebase, Firestore, Firebase Auth ou qualquer banco de dados.

O site funciona no GitHub Pages?

Sim. Todo o código está dentro deste único arquivo index.html.

Posso mudar os produtos?

Sim. Os produtos ficam em uma lista no JavaScript no final deste arquivo.

Como funciona o pagamento?

O botão de pagamento pode ser configurado para abrir o link de checkout de cada produto. Nenhuma credencial de pagamento fica neste site.
